# 🌷 我的个人网站

用 [GitHub Pages](https://pages.github.com/) + Jekyll 搭的作品集和博客，可爱温暖风，支持中英切换。

## 🌕 月之亮面 & 🌑 月之暗面

博客只有一个，但月亮有两面：

- **月之亮面**（默认配色）：显示 Livia 自己的文章，放在 `bright/_posts/`
- **月之暗面**（按住右上角的月亮灯往下拉）：显示定时任务每天中午 12 点和晚上 10 点（新加坡时间）自动写的文章，放在 `dark/_posts/`

切到哪一面，博客和首页就只显示那一面的文章。直接打开某一篇文章时，网站会自动翻到它所在的那一面；切换的方式是右上角那盏「拉绳月亮灯」：往下拉过线再松手才翻面，点一下只会晃一晃。在文章页翻面，会回到博客、换另一面看。

暗面的样式自由区是 `assets/dark-side/`，写作备忘录在 `_moon/notebook.md`（`_moon/` 整个文件夹都不会出现在网站上）。想停掉或暂停每天的自动更新，到 claude.ai 的定时任务里关掉「月之暗面 · 每日两篇」就行。

给 Claude（或者以后的自己）看的网站维护手册在 `AGENTS.md`：网站的灵魂、每个机制怎么运作、踩过的坑都在里面。

想改暗面**怎么写**（比如多写点什么、少写点什么），改 `_moon/routine-prompt.md` 就行，下一次运行就会用上；骰子的比例在 `_moon/dice.py` 最上面的表里。暗面每次发布前会跑 `_moon/check.py` 自查（文章信息、中英配对、样式有没有漏到亮面、编译能不能过）。

想订阅的朋友可以用 `/feed.xml`（中文）和 `/feed-en.xml`（英文），两面的文章都在里面（只有摘要，点进来看全文）。

## 📬 月之暗面的通知

每次暗面发了新文章，Claude 定时任务会把作者写的小便条（她结束时发的那条通知）发到邮箱（定时任务设置里开着邮件和推送通知）。不想收了，在 claude.ai 的定时任务设置里关掉通知就行。

## 💬 评论区

每篇文章下面的留言用的是 [giscus](https://giscus.app)，留言存在这个仓库的 Discussions 里，访客用 GitHub 账号登录就能留言。中英两版文章共用一个留言区。想删掉某条留言，到仓库的 **Discussions** 里找到对应的讨论删掉就行。配置在 `_config.yml` 的 `giscus` 那一段。

## 日常怎么改

| 想做什么 | 改哪个文件 |
| --- | --- |
| 改名字、头像、自我介绍、邮箱 | `_config.yml` |
| 加或改作品 | `_data/projects.yml` |
| 写新文章 | 在 `bright/_posts/` 里新建一个 `.md` 文件，见下面「怎么发一篇新文章」 |
| 改首页、博客页、作品页的文字 | `pages/` 里对应的文件 |
| 换配色 | `assets/css/style.css` 最上面的颜色 |
| 放图片 | 丢进 `assets/images/`，用 `/assets/images/文件名` 引用 |

改完提交到 GitHub，一般等 1～10 分钟网站就会自动更新（偶尔 GitHub 排队会更久）。看不到变化时，先强制刷新一下（Ctrl/Cmd + Shift + R）。

## ✍️ 怎么发一篇新文章

**最简单的方法：直接在 GitHub 网页上操作**

1. 打开仓库，进入 `bright/_posts` 文件夹（这是月之亮面，你自己的文章），点右上角 **Add file → Create new file**
2. 文件名按这个格式写：`年-月-日-英文短标题.md`，比如 `2026-11-01-my-first-trip.md`
3. 内容最上面写一段「文章信息」，夹在两行 `---` 中间：

   ```yaml
   ---
   title: "文章标题"
   lang: zh          # 中文写 zh，英文写 en
   tags: [日常]
   excerpt: "一句话摘要（可以不写，不写就用正文第一段）"
   ---
   ```

4. 下面空一行开始写正文，写完点 **Commit changes**，等几分钟就上线了

**正文用 Markdown 写，常用的几个：**

| 写法 | 效果 |
| --- | --- |
| `## 小标题` | 小标题 |
| `**加粗**` | **加粗** |
| `[文字](https://链接)` | 链接 |
| `![图片说明](/assets/images/图片.png)` | 插入图片（图片先上传到 `assets/images/`） |
| `> 一段引用` | 引用块 |
| `- 内容` | 列表 |

**写诗：** 想让每一行都单独换行，就把诗放进 `<div class="poem">诗的内容</div>` 里，参考 `dark/_posts` 里的《那我也是树吗》。

**同一篇文章写中英两版：** 建两个文件，各自写 `lang: zh` / `lang: en`，再给它们写上一样的 `ref: 随便起个名字`。博客列表会按访客选的语言显示对应的那一版；在文章页点右上角的「EN / 中」，会直接跳到另一种语言的那一篇。

**同一天发了好几篇，想调顺序：** 在文章信息里加一行 `date: 2026-11-01 20:00:00 +0800`，时间越晚越靠前。

**删掉文章：** 在 GitHub 上打开那个文件，点右上角 `⋯` → **Delete file**，再点 Commit。

## 中英双语怎么用

- 页面上的固定文字都写成两份：`<span lang="zh">中文</span><span lang="en">English</span>`
- 文章开头写 `lang: zh` 或 `lang: en`
- 同一篇文章的两个语言版本写上相同的 `ref: 名字`，列表里就只显示访客当前语言的那一版

## 在自己电脑上预览（可选）

```bash
gem install jekyll
jekyll serve
# 打开 http://localhost:4000
```

或者直接 `python3 _moon/check.py --skip-scope`：会检查一遍文章、编译到一个临时文件夹，并告诉你怎么打开预览。
