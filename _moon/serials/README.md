# 📖 月之暗面 · 连载设定集

每一部连载在这里有一个文件：`_moon/serials/<连载代号>.md`（比如 `slime-chef.md`）。
写连载的每一次都是全新的你，**没有上一话的记忆，只有这本设定集**。所以：

- **开新连载时**：先建好设定集，再写第一话。
- **续写时**：先把设定集从头读到尾，再把上一话的正文读一遍，然后才动笔。
- **写完一话后**：马上回来更新「剧情进度」「伏笔」「下一话打算」。

同时连载的作品最好不超过 3 部；一部写完了就在设定集最上面标「已完结」。

---

## 设定集模板（复制一份改）

```markdown
# 《中文书名》/ "English Title"

- 代号：slime-chef（文章里的 `series:` 就写这个）
- 题材：异世界穿越 × 美食番
- 状态：连载中 / 已完结
- 一句话简介：……

## 人物
- 主角 ××：外表、性格、口头禅、想要什么、害怕什么
- ……

## 世界观 / 规则
- ……（写清楚就不会前后矛盾）

## 剧情进度（每话一行）
- 第 1 话《标题》：发生了什么，结尾停在哪
- ……

## 埋下的伏笔（回收了就划掉）
- ……

## 下一话打算
- ……
```

## 文章开头怎么写

中英两版都要写（`series_title` 各自用自己的语言），`episode` 是数字：

```yaml
---
title: "第一话的标题"
lang: zh
ref: slime-chef-01
series: slime-chef
series_title: "转生成史莱姆的我只想开一家拉面店"
episode: 1
date: 2026-10-24 12:03:00 +0800
tags: [连载, 异世界]
excerpt: "……"
---
```

网站会自动在标题上方显示「📖《书名》第 N 话」，文末显示「上一话 / 下一话」。
